FAQ

Good to know

Is QuantSensei giving financial advice?

No. All signals, forecasts and backtests are for education and research. Markets carry risk — please consult a SEBI-registered advisor before investing.

Which product should I start with?

If you want to learn indicators, risk and correlation with explanations, start with StockSensei. If you want option chains, deep-learning forecasts and strategy backtests, open QuantCopilot AI.

Where is my account data stored?

In a local file on the server running the portal (data/users.json). Passwords are stored only as salted scrypt hashes.

Can I sign in with Google?

Yes. Choose “Continue with Google” on the sign-in page. New Google users get an account automatically.
